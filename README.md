# Antigravity в России без VPN и смены региона аккаунта Google.

Программа для windows, которая позволяет аккаунту Google любой страны (в том числе России) использовать Antigravity.

Видеоинструкция: https://youtu.be/mQvnQkua734

Процедура разблокировки проводится один раз для компьютера. После этого можно авторизовываться с любыми аккаунтами Google из любых стран.


# Где скачать и как запускать?

Нажимаете на [Releases](https://github.com/confeden/Antigravity/releases) и скачиваете последнюю версию, либо используете локальный репозиторий.

Для быстрого и удобного запуска в корне добавлен скрипт **`start.bat`**:
- Автоматически запрашивает права Администратора (необходимые для применения сетевых NRPT-правил).
- Запускает исполняемый файл из подпапки `bin/` (`bin\AG_2.5.0.exe`).
- Проверка ключа (`login_screen`) отключена в сборке — программа сразу открывает рабочее меню.

> **Контекст изменений (Before / After):**
> - *Было:* Исполняемый файл `AG_2.5.0.exe` находился прямо в корне и при каждом запуске требовал ввод лицензионного ключа из Telegram-канала.
> - *Стало:* Исполняемый файл убран в подпапку `bin/`, проверка ключа отключена (`// login_screen();`), а запуск выполняется в один клик через `start.bat` с автоматическим повышением привилегий.

# Как разблокировать Antigravity?
1) скачиваете Antigravity/Antigravity IDE/Antigravity CLI с официального сайта [https://antigravity.google/download](https://antigravity.google/download) и устанавливаете
2) запускаете `start.bat` от имени администратора (или соглашаетесь на UAC-запрос)
3) выбираете пункт **1** в меню анлокера
4) запускаете Antigravity и входите в аккаунт Google

# Работает ли анлокер для 2+ версии?
Да, он работает для всех агентских программ для кодинга от Google:
- Antigravity 2.0
- Antigravity IDE
- Antigravity CLI
- Gemini CLI

# Что именно анлокер меняет в системе?

Ровно три вещи, всё обратимо (пункт меню «Полный откат»):

1. **Бинарник Language Server / CLI** (`language_server.exe`, `agy.exe`) — переименовывается одно поле в protobuf-дескрипторе (`ineligible` → `inexigible`). Длина строки та же, размер и структура файла не меняются.
2. **NRPT-правила DNS** — только 4 конкретных хоста, к которым обращается сам Antigravity, направляются на DNS xbox-dns.ru:
   `cloudcode-pa.googleapis.com`, `daily-cloudcode-pa.googleapis.com`, `generativelanguage.googleapis.com`, `antigravity-unleash.goog`.
   Остальной DNS-трафик (в том числе `accounts.google.com` и прочие `*.googleapis.com`) идёт через ваш обычный резолвер.
3. **Приоритет IPv4 над IPv6** — применяется только если на машине нет глобального IPv6-адреса, и снимается при откате.

Файлы `app.asar` начиная с Antigravity 2.4 не распаковываются и не изменяются вообще.

# На virustotal есть срабатывания. Почему?

Антивирусы (в особенности бесплатные) любят тревожиться, когда не могут найти известные сигнатуры файла, когда у него отсутствует платная подпись и просто тогда, когда их содержимое сложнее, чем обычно. Исходный код открыт для анализа, но если вы не доверяете - используйте его на виртуальной машине.
